# Contributing

1. Fork repo → branch fitur (`feat/<deskripsi>`).
2. Tidak boleh menambahkan file > 50 MB (lihat `.gitignore`) — ROM/firmware **tidak** didistribusikan di sini.
3. Untuk dokumen environment-specific (`docs/DEV-TOOLKIT.md`), update bersama perubahan tools.
4. Laporkan bug via GitHub Issues; sertakan: device, firmware version, recovery, langkah repro.
5. OpenCode agents: gunakan skill yang tersedia di `skills/opencode/` (lihat OpenCode docs).
